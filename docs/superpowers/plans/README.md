# 現場日報アプリ 実装計画の全体構成

設計書 `docs/superpowers/specs/2026-10-30-genba-nippou-design.md` は4つの独立した部分系に分かれるため、計画も4本に分ける。各計画は単体で動く成果物を出す。順番に実施し、前の計画が終わってから次の計画を書く（前の計画で決まったファイル名・型を前提にするため）。

| # | 計画 | 成果物 | 設計書の章 |
|---|---|---|---|
| 1 | `2026-10-30-phase1-core-daily-report.md` | ログイン、現場・マスター管理、日報入力（6表・前回コピー・下書き）、提出／承認、重要事項の状態管理、アプリ内集計、繰越初期値、ガイド骨格、Vercelデプロイ | §2〜§7、§11、§12（骨格）、§13（画面のみ）、§16 |
| 2 | phase2-excel-export（未作成） | Python関数でV33原本xlsmを埋めるExcel出力、行挿入、前月繰越、プルダウン再設定、原本差分テスト | §8、§14（Excel） |
| 3 | phase3-estimate-link（未作成） | 積算書のExcel／PDF取り込み、確認画面、版管理、自社施工選択、出来高入力の「内訳から選ぶ」、請求資料（簡易Excel） | §9 |
| 4 | phase4-pdf-photos-import（未作成） | PDF出力（日報・集計・請求資料・写真ページ）、写真添付、マスターExcel取り込み、ガイド完成 | §10、§12、§13（取り込み） |

第1計画の時点では、日報の「作業内容」行は手入力のみ（種別＝追加）。第3計画で積算内訳からの選択を足す。
