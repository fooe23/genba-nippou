# 追加・変更の精算

客先から「これも追加で」「ここを変えて」と言われた仕事は、指示を受けた日と、見積が出て金額が決まった日が別になるのがふつうです。このアプリでは、**指示を受けた日は現場で件を登録し、金額が決まったら事務所で一覧画面に確定額を入れる**、という 2 段階で記録します。同じ金額を 2 か所に入れ直す必要はありません。

## 1. 指示を受けた日にすること（現場）

日報を一度「下書き保存」してから、次の 2 つを入れます。

1. **件を登録する**：日報の「重要事項（件）」に、内容を書いて「件を追加」します。あわせて次を入れます（金額見込み以外は、わかる範囲でかまいません）。
   - **種別**：追加指示／増（数量増）／仕様変更／減／客先都合（手待ち・待機）／やり直し／その他
   - **指示者**：誰が指示したか
   - **指示方法**：口頭・電話・メール・書面・その他
   - **金額見込み（円）**：この時点でわかる大まかな額。あとで確定額を入れても、この見込み額は消えません（予測として残ります）。
2. **作業内容の行に区分と件を付ける**：その日にやった追加・変更の作業は、「作業内容」の行の区分を「追加」「増」「変更」「減」にし、「根拠の件」に今登録した件を選びます。

この「根拠の件」を選んでおくと、その件にかかった人工と実績原価が自動で件ごとにまとまります。金額の確定はこの日にする必要はありません。

## 2. 見積が出たらすること（事務所）

見積書を客先に出したら、金額を件に入れます。

1. 現場を開き、「追加・変更」を押します（協力会社のアカウントには出ません）。「追加・変更の一覧」が開きます。出力画面の「変更増減 精算資料」の欄にあるリンクからも開けます。
2. 件ごとに「精算方法」を選びます。
   - **一式**にしたら、「確定額」（円）を入れます。数量では表しにくい仕事を、おおよその一括の額で決めるときに使います。
   - **見積**にしたら、「見積額」（円）を入れます。材料などがはっきりして、細かい見積の額が出たときに使います。
   - **常用**にしたら、「常用単価」（客先に請求する 1 人工あたりの円）を入れます。単価の初期値は、その現場の「常用単価の既定」です（管理 → 現場で決めます）。
3. 見積を出した日などを「確定日」に入れます（任意。表示のためだけの日付で、計算には使いません）。見積にした件では、この欄が「見積日」になります。
4. その行の「保存」を押します。「保存しました」と出て、その行の「精算額」が計算し直されます。

確定額・見積額と常用単価は円単位の整数で入れてください。完了した現場の一覧は見るだけで、変更できません。

## 3. 4 つの精算方法と計算

| 精算方法 | 入れるもの | 精算額 |
|---|---|---|
| 未定（初めはこれ） | なし | その件に紐づく作業の行の「提案額」の合計 |
| 一式 | 確定額 | 確定額そのもの |
| 見積 | 見積額 | 見積額そのもの（計算は一式と同じ） |
| 常用 | 常用単価 | その件に紐づく作業の行の人工の合計 × 常用単価（円未満は切り上げ） |

**提案額**は、実績原価に経費率と利益率を掛けて切り上げた額です。見積が出る前の「仮の額」として使います。ただし**減の作業の行**の提案額は、原価からは計算せず、その行の申告額（マイナス）がそのまま提案額になります。

**減の件**は、確定額・見積額を**正の数で**入れます。精算額を出すときにアプリがマイナスにして引きます（−30,000 のように入れる必要はありません）。

**一式・見積・常用にした件**では、その件に紐づく作業の行の提案額は数えません。件の精算額（確定額・見積額、または人工 × 単価）に置き換わります。作業の行の区分が何であっても同じです。確定額と行の提案額が二重に足されることはありません。

見積が先に出て、作業の行がまだ無い件も、一式・見積で額を入れれば精算額に数えます（「行数 0」で出ます）。

**一式と見積の使い分け**：一式は、数量で表しにくい仕事をおおよその一括の額で決めるときの方法です。見積は、材料などがはっきりして細かい見積の額が出たときの方法です。計算はどちらも同じ（入れた額がそのまま精算額）で、資料での書き方だけが違います（客先用の精算の欄は「一式（11/06）」「見積（11/06）」のように出ます。日付は確定日・見積日で、無ければ「一式」「見積」だけ）。

**一式から見積に切り替える**：はじめ一式でおおよその額を入れておき、細かい見積が出たら、一覧でその件の精算方法を「見積」に変え、「見積額」と「見積日」を入れ直して「保存」します。入れてあった額は見積額の欄にそのまま残るので、直すところだけ変えれば済みます。

## 4. 種別ごとの数え方

件の種別によって、精算資料のどの区分に入るかが決まります。

| 件の種別 | 精算での扱い |
|---|---|
| 追加指示 | 追加 |
| 増（数量増） | 増 |
| 仕様変更 | 変更 |
| 減 | 減（マイナス） |
| 客先都合（手待ち・待機） | **追加**として請求に入れる |
| その他 | **追加**として請求に入れる |
| やり直し | **精算に入れない**（自社の都合のため） |

やり直しの件も、精算資料の「件ごとの精算」には参考として出ます。精算額の欄に「（参考）」と額が付き、合計には足されません。

## 5. 精算資料の読み方

出力画面の「変更増減 精算資料」から出します。「客先用（精算のご提案）」と「社内確認用」の 2 種類があり、ここで説明するのは主に**社内確認用**（題名「変更増減 社内確認用」）の読み方です。客先用との違いは次の節を見てください。

- **精算のサマリー**：区分（追加・増・変更・減）ごとの件数・申告額・提案額と、**精算額**が出ます。いちばん下の「精算提案額」が、当初の金額に追加・増・変更を足し、減を引いた合計です。
- **件ごとの精算**：件の一覧です。見込み額、精算方法、確定額（一式・見積）または「常用 N 人工 × 単価」、確定日、紐づく作業の行数、投入人工、提案額、精算額が並びます。見込み額から確定額へどう変わったかがここで分かります。
- **件なしの行**：区分を「追加」「増」「変更」「減」にしたのに、「根拠の件」を選んでいない作業の行は、まとめて「件なし」の 1 行に出ます。この行は提案額がそのまま精算額になります。件を選び直せば、その件の精算に入ります。
- **月を指定したとき**：明細一覧と区分ごとの件数・申告額・提案額は、その月の分だけです。**精算額は月末までの累計**で、列名が「精算額（累計）」になります。常用の人工も月末までの累計で計算します。月をまたぐ件でも、見積の額と合います。
- **実績原価は出ません**。実績原価の列は、客先用にも社内確認用にも載せません。実績原価は、社内向けの「追加・変更の一覧」でだけ見られます。

## 6. 客先用と社内確認用の違い

出力画面の「変更増減 精算資料」には、同じ期間を選んだまま出せる 2 組のボタンがあります。どちらも「PDF プレビュー」「PDF ダウンロード」「Excel」です。

| | 客先用（精算のご提案） | 社内確認用 |
|---|---|---|
| 題名 | 追加・変更工事 精算のご提案（案） | 変更増減 社内確認用 |
| 渡す相手 | 客先 | 社内のみ |
| 見せるもの | 区分ごとの件数と金額、件ごとの金額、日付ごとの作業の明細（根拠） | 見込み額、提案額、精算額、件ごとの精算の詳細など |
| 見せないもの | 実績原価、見込み額、原価からの提案額、経費率・利益率、やり直しの件、件なしの内訳 | 実績原価（これは社内確認用にも載りません） |
| 見積中の件 | 金額を出さず、合計にも入れない | 提案額で合計に入れる |
| ファイル名 | 現場名_精算のご提案_20261106.pdf など | 現場名_変更増減_社内確認用_20261106.pdf など |

客先用は、客先に出してよい数字だけで作ってあります。**客先に渡すのは客先用**です。社内確認用は、金額の中身を社内で確かめたいときに使います。

- **客先用の中身**：「精算のまとめ」（当初請負金額、追加・増・変更・減の件数と金額、いちばん下に精算提案額）、「件ごとの内容」（件、ご指示、精算方法、金額、客先確認のあり／なし）、「作業の明細（根拠）」（日付、区分、工種、施工内容、数量、人工、指示者・方法、件、確認）、発行者とお客様確認欄です。宛名には客先名が入り、「様」または「御中」が付きます（「様」「御中」で終わる名前はそのまま、「株式会社」などが付く名前は御中、それ以外は様。客先名が無いときは「お客様 各位」）。
- **見積中の件**：まだ確定額が決まっていない件は、客先用では金額を「—」にし、精算提案額にも入れません。「見積中の件（N 件）は金額に含めていません。確定しだい改めてご提示します」という注記が付きます。一式・見積で額が無い件、常用で単価が無い件も、見積中と同じ扱いです。
- **精算提案額が両方で違うことがあります**。客先用は見積中の件を除くので、社内確認用の精算提案額（未定の件は提案額で足す）より小さくなったり、同じになったりします。確定した件の金額は両方で同じです。社内確認用のまとめには「客先提示額（見積中を除く）」の行があり、客先用の精算提案額とそのまま突き合わせられます。
- **使い分け**：打合せで客先に見せる・渡すのは客先用です。社内で「いくらで出すか」を相談するときや、見積中の件の提案額を見たいときは社内確認用を使います。

## 7. お客様用の日報

日報の画面から、金額の無い「現場日報（お客様用）」PDF を出せます。その日の作業を客先に見せたり、渡したりするときに使います。

- **載るもの**：現場名、日付（曜日）、天候、作業責任者、作業時間（共通時間の開始〜終了）。「本日の作業」（区分・工種・施工内容・数量・単位・人工）と「作業員 N 名・合計 M.M 人工」。「追加・変更のご連絡」（その日の日報に登録した件の番号・種別・ご指示・内容。やり直しは載せません。無いときは「ありません」）。お客様確認欄と作成者。
- **載らないもの**：作業員の氏名と時間、日当、労務費、車両・リース・現金購入・買掛の金額、原価集計、出来高・進捗率、連絡事項。
- **出し方**：保存した日報の見出しの横に、「PDF」「PDF 保存」「CSV」と並んで「お客様用 PDF」「お客様用 保存」があります。「お客様用 PDF」は新しいタブで開き（プレビュー）、「お客様用 保存」はファイルとして保存します（ファイル名は 現場名_日報（お客様用）_2026-11-06.pdf の形）。1 日分だけで、月まとめのお客様用はありません。協力会社のアカウントには出ません。
- **お客様確認欄**：客先確認を記録済みなら確認者名・日時・メモが入り、未記録なら空欄の枠 3 つ（確認者名／日付／サイン）が出ます。

よくある流れは次のとおりです。

1. 当日の日報を保存し、「お客様用 PDF」で内容を確かめる。
2. 次のどちらかで客先に渡す。
   - 「お客様用 保存」でファイルにして、メール等で送る（メール送信の機能はアプリにありません。保存したファイルを自分で添付して送ります）。
   - その場で画面や印刷を見せて、空欄にサインをもらう。
3. 了承を得たら、日報の「客先確認を記録」で確認者名などを記録する（記録すると、次に出すお客様用 PDF の確認欄に入ります）。

## 8. PDF のプレビューとダウンロード

PDF には、開くボタンと保存するボタンの 2 つがあります。出力画面では「PDF プレビュー」「PDF ダウンロード」、日報の画面では「PDF」「PDF 保存」（お客様用は「お客様用 PDF」「お客様用 保存」）です。

- **PDF プレビュー**（日報の画面では **PDF**）：新しいタブでそのまま開きます。内容を確かめたいとき、そのまま印刷したいときに使います。
- **PDF ダウンロード**（日報の画面では **PDF 保存**）：ファイルとして保存します。ファイル名を日本語のまま残したいときはこちらです。

## 9. よくある迷い

**「追加」と「増」はどう違う？**　新しく別の仕事が増えたら「追加」、同じ流れの中で数量が増えたら「増」です（例：棚を 1 台新しく作るのは追加、張るクロスの面積が増えたのは増）。精算の計算はどちらも同じで、資料では区分が分かれて出ます。

**常用の単価は、件ごと？**　件ごとです。ある件の単価を変えても、ほかの件の単価は変わりません。現場の「常用単価の既定」は、常用を選んだときの初期値に使うだけです。既定を変えても、保存済みの件の単価は変わりません。

**確定額を入れたら、見込み額は消える？**　消えません。見込み額は予測として残り、精算資料に「見込み → 確定」と並んで出ます。

**確定日は何のため？**　見積を出した日などの記録です（見積の件では「見積日」と出ます）。表示だけで、精算額の計算には使いません。

**減の確定額に、マイナスを付けるの？**　付けません。正の数で入れてください。

**金額を入れたのに、資料の額が思った額にならない。**　精算方法が「未定」のままだと、確定額は使われません。一式・見積・常用のどれかにして保存したか、確かめてください。「保存しました」と出ていなければ、保存されていません。
