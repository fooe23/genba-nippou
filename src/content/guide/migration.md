# 移行時の繰越初期値の登録

Excelの日報で進めていた現場を、途中からアプリに切り替えるときに行います。一度登録すれば、その後は触りません。最初からアプリで入力する現場では不要です。

## 準備

- 切り替え前に最後に使っていたExcelの日報ブック（V33など）を開きます。
- 管理者のアカウントで、アプリにログインします。

## 手順

### 1. Excelで累計を確認する

1. ブックの「マスター」シートを開きます。
2. 下の方にある「作業員別 当月集計」の表を見ます。
3. 作業員ごとに、次の2つの列の数字を控えます。
   - **G列：累計人工**
   - **H列：累計労務費**

この表では、C・D列の黄色いセルが「前月繰越」（人工・労務費）で、G・H列は「前月繰越 + 当月分」の累計です。切り替え前の最後の月の、G・H列を使います。

### 2. 基準日を決める

基準日は、**アプリで日報を入力し始める最初の日**です。この日より前の分が、繰越初期値になります。

### 3. アプリに登録する

1. 画面下の「管理」→「現場」を開き、その現場を選びます。
2. 「④ 繰越初期値」を開きます。作業員が出ない場合は、先に「③ この現場で使うマスター」で作業員を選んで保存してください。
3. 作業員ごとに、次の3つを入れます。
   - 人工（Excelの累計人工）
   - 労務費（Excelの累計労務費）
   - 基準日（アプリで入力し始める最初の日）
4. 作業員ごとに「（作業員名）の繰越を保存」を押します。

### 4. 確かめる

現場の「集計を見る」→「作業員別累計」で、累計が「繰越初期値 + 表示期間」になっていることを確認します。

## 注意

- **1回だけの登録です。** 毎月の入力は不要です。
- 基準日より前の日報は、アプリには入れません（繰越初期値に含まれているため）。基準日以降の日報だけを入力してください。
- 数字を間違えたときは、同じ画面で書き直して保存し直せます。
- 考え方は「前月繰越の考え方」の章を見てください。
