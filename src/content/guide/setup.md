# 使い始める前の準備（管理者）

現場で日報を入れ始める前に、管理者が次の3つを済ませておきます。どれも画面下の「管理」から行います。一度登録すれば、毎日の入力で同じものを打ち直す必要はありません。

## 1. 現場を登録し、確認者・承認者を割り当てる

「管理」→「現場」→「新規作成」で現場を作り、「② 担当者」で人を割り当てます。

- **担当**：日報を書く人。社員は割り当てがなくても全現場に入力できるので、主に協力会社の職長を割り当てます。
- **確認**・**承認**：提出された日報を承認・差戻しする人。**承認は割り当てた人（と管理者）しかできません。** 現場ごとに最低1人は割り当ててください。
- 「① 現場情報」の「契約の状態」は、契約金額が決まっていれば「確定」、まだ決まっていなければ「未確定（概算）」にします。未確定にすると「概算金額（見積提示額・円）」の欄が出るので、客先に出した見積の金額を入れておきます。
- 「常用単価の既定（客先請求・円／人工）」は、常用（工数）で精算する追加・変更が多い現場で入れておくと、「追加・変更」の一覧で精算方法を「常用」にしたときの単価の初期値になります（空でもかまいません。件ごとに変えられます）。
- 「③ この現場で使うマスター」で、その現場で使う作業員・取引先・車両・リース品にチェックを入れると、日報の選択肢がその現場のものだけになります。「すべて選択」でまとめてチェックできます。何も選んでいない種類は、有効なもの全部が日報に出ます。取り込みで作業員を増やしたときは、ここで現場に追加してください。

## 2. マスターを登録する（作業員の日当・車両・取引先・リース品）

「管理」→「マスター」で、作業員・取引先・車両・リース品を登録します。

- **作業員の日当**は「適用開始日」付きで登録します。**適用開始日は、日報の日付より前（または同じ日）にしてください。** 日報の日付より後の日付で登録すると、その日報では日当が「未設定」になります。
- 日当が変わったときは、上書きせずに新しい適用開始日で追加します。過去の日報は当時の日当のまま残ります。
- 車両は燃費と燃料単価、リース品は単価を登録すると、日報で自動計算されます。
- 作業員には「残業単価（円/H）」も登録できます（任意）。空欄の人は 日当 ÷ 8 × 1.25 で計算します。
- 「労務の設定」タブの「追加分の提案金額」で、追加・増・変更の工事を客先に提案するときの経費率（%）・利益率（%）と、提案書に載せる会社名・担当者・連絡先を決めます。はじめは経費率 15%・利益率 10% です。
- 「労務の設定」タブで、人工・残業の計算に使う数字（1人工の基準時間 7.5H、固定残業の上限 8H、割増率 1.25、残業単価の基準時間 8H）と、新しい日報の共通時間の既定を変えられます。現場ごとの共通時間の既定は、管理 → 現場 → ① 現場情報で決められます。

### Excel のマスターをまとめて取り込む

Excel 日報（雛形 V33／V34）の「マスター」シートに作業員・取引先・車両・リース品があれば、まとめて取り込めます。

1. 「管理」→「マスター」→「取り込み」タブを開きます。
2. 「単価の適用開始日」を確かめます（最初は今日）。日当・リース単価が今と違う人・品目は、この日付から新しい単価になります。
3. 「ファイル」で Excel（.xlsm／.xlsx）か CSV を選びます。ファイルは端末の中で読み取り、サーバーには送りません（10MB まで）。
4. 確認画面に、種別ごとの **新規・更新・変更なし・エラー** の件数と一覧が出ます。更新の行は「項目：変更前 → 変更後」で変わる所だけが出ます。取り込みたくない行はチェックを外します。
5. 「取り込む」を押すと確定です。結果の件数が出て、マスターの一覧に反映されます。下の「取り込み履歴」に、日時・実行した人・ファイル名・件数が残ります。

取り込みの決まり：

- **名前で突き合わせます。** 名前（前後の空白は除く）が同じ行は更新、無い行は追加します。
- **空の欄は「変更しない」です。** Excel で空欄の項目は、アプリの値をそのまま残します（消したいときはアプリの編集画面で消します）。残業単価の 0 も空欄と同じ扱いです。
- **日当・リース単価は履歴に追加します。** 適用開始日の時点の単価と違うときだけ、その日付の単価を追加します（同じ日付があれば上書き）。過去の日報の単価は変わりません。
- **Excel に無い行は消しません。** 使わなくなった人・品目は、アプリの編集画面で「無効にする」を押します。無効の行を取り込んでも、無効のままです。
- 名前が空の行、日当などが数値でない行、同じ名前が 2 回出る行（後の方）はエラーとして表示し、取り込みません。
- アプリに同じ名前の行が 2 件以上登録されている名前も、エラーとして取り込みません。管理 → マスターで 1 件に整理（使わない方の名前を変える など）してから取り込みます。

CSV は種別ごとに 1 ファイルです。1 行目に見出し、2 行目からデータを入れます（No. 列は有っても無くてもかまいません。列の順番は自由です）。文字コードは UTF-8 と Shift_JIS のどちらでも読めます。

| 種別 | 見出し |
|---|---|
| 作業員 | 作業員名, 区分（職種）, 設定日当（円）, 残業単価（円/H）, 備考 |
| 取引先 | 取引先名, 区分, 担当者, 備考 |
| 車両 | 車両名／ナンバー, 種別, 燃費(km/L), 備考 |
| リース品 | 品目名, 規格, リース単価（円/日）, 備考 |

Excel の「備考」はアプリの「メモ」、取引先の「担当者」は「連絡先」、車両の「種別」は「区分」に入ります。

各マスターの一覧と編集画面には「更新 日時 氏名」（名前・職種などを最後に更新した日時と人）が出ます。単価の改定は、編集画面の「単価の改定履歴」に更新した人が出ます。

## 3. 協力会社の職長に使わせる場合（アカウント）

協力会社の人には、業務日報アプリとは別に、現場日報専用のアカウントを作ります。

1. 「管理」→「アカウント」→「協力会社アカウントを追加」で、会社名・氏名・メールアドレス・初期パスワードを入れて「作成」します。
2. 作ったアカウントを、その人が入る現場の「② 担当者」で**担当**に割り当てます。協力会社のアカウントには、割り当てられた現場だけが表示されます。
3. 本人には、現場日報のURLとメールアドレス・初期パスワードを伝えます。協力会社のアカウントは業務日報アプリにはログインできません。

社員のアカウントは、これまでどおり業務日報アプリの「社員・権限管理」で作ります。作った社員は現場日報にも同じメールアドレスとパスワードでログインできます。

## 準備ができたら

ホームに現場が出ていれば準備完了です。毎日の入力は「日報の入力手順」の章を読んでください。
