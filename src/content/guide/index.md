# ガイドの使い方

このガイドは、現場日報アプリの操作手順と考え方をまとめたものです。分からなくなったら、画面下の「ガイド」から開いてください。

## 章の一覧

- **使い始める前の準備（管理者）**：現場と確認者・承認者の割り当て、作業員の日当などのマスター登録、協力会社アカウントの作り方。
- **日報の入力手順**：毎日の日報の書き方。前回コピー、行の追加、入力中の自動保存。
- **提出と承認**：担当・確認・承認の役割と、提出から承認までの流れ。
- **完了現場と削除**：完了した現場の見方（閲覧のみ）と、管理者による現場の削除・復元・削除ログ。
- **集計の見方**：月次集計・現場原価集計・出面一覧・作業員別累計。
- **前月繰越の考え方**：Excelの「前月繰越」がアプリでは不要になる理由。
- **移行時の繰越初期値の登録**：途中から使い始める現場で、旧Excelの累計を1回だけ入れる手順。
- **Excel 出力と帳票（PDF・CSV）**：原本 Excel、工事原価集計表、日報の PDF・CSV の出し方。
- **PDF の見方**：工事原価集計表の①〜⑦と、日報 PDF の並び・署名欄。
- **追加・変更の精算**：追加・増・変更・減の件を、見積が出たあとに一式・常用で確定する手順と、精算資料の読み方。

積算書の連携・写真の添付は、機能の追加に合わせて今後追記します。

## 読み方のコツ

- 画面のボタン名は「 」で囲んで書いています（例：「下書き保存」）。画面の表示と同じ名前を探してください。
- 迷ったら、まず「日報の入力手順」だけ読めば毎日の入力はできます。
- 管理者だけが使う操作には、章の中で「管理者」と書いてあります。
