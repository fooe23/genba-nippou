# 実行予算・予算と実績

受注の内訳（下請の現場はゼネコン・元請けから渡された内訳（注文書）、自社が元請けの現場はお客様に出した見積書の内訳）と、自分たちで組んだ実行予算を、現場ごとに**工種**で分けて持ちます。できること：工種・実行予算・受注の内訳を入れる（画面と Excel）、日報の作業内容の行で工種を選ぶ、過去の日報の工種の文字を工種に読み替える（読み替え表）、「**予算と実績**」の画面で工種ごとに内訳の金額・実行予算・実績・進み具合・見込みを比べる、進み具合の % を上書きする。

これらの画面を使えるのは**社員と管理者だけ**です。協力会社のアカウントには、金額・予算・内訳・実績・見込みは見えません（日報で選ぶための工種の名前だけ見えます）。

現場を開き、「**予算と実績**」または「**実行予算・受注の内訳**」を押すと開きます（2 つの画面は互いに行き来できます）。完了した現場は閲覧と Excel の書き出しだけできます。

## 1. 工種

実行予算と内訳を分ける単位です（例：剥離・ブラスト・塗装）。

- 「＋ 工種を追加」で足し、名前を入れて「工種を保存」を押します。↑↓ で並べ替えられます。
- 名前を変えるのはこの画面だけです。Excel で名前を変えると、**別の工種として足されます**。
- 実行予算・受注の内訳・日報の工種・読み替え表で使われている工種は消せません（進み具合の % を上書きしたことのある工種も消せません）。
- 「経費」「減分」「現場全体」は Excel の印に使うので、工種の名前にはできません。

## 2. 実行予算

工種ごとのまとまりの下に、施工者ごとの行を入れます。協力会社が 2 社・3 社でも、行を足すだけでほかの工種はずれません。

| 項目 | 施工者 | 入れ方 |
| --- | --- | --- |
| 労務 | 自社 | 人工 × 日当。単価の初期値は「予算の標準日当」です（行ごとに書き換えられます） |
| 請負 | 協力会社 | 1 式いくら、など |
| 常用 | 協力会社 | 人工 × 単価 |
| 材料・リース・その他 | — | 工種に分けず「現場全体」に入れます |

- **予算の標準日当**は全社の設定です（管理 → マスター → 労務の設定。既定は 20,000 円）。管理者が変えられます。現場の「常用単価の既定」は客先に請求する単価なので、予算には使いません。
- 協力会社は、マスターで**協力会社の印**のある会社から選びます。
- 金額は数量 × 単価で、1 円未満は四捨五入します。
- 「実行予算を保存」を押すと、実行予算の行を全部入れ替えます。

## 3. 受注の内訳

受注の内訳の行（区分・名称・規格・数量・単位・単価・金額）を入れ、右端の「**工種（識別）**」でどの工種の分かを選びます。

- **経費**（諸経費など）と**減分**（減工分など）は工種に入れず、内訳の金額の合計にだけ数えます。
- 区分は「当初」と「変更」です。変更の内訳が届いたら、区分を「変更」にして行を足します。
- 工種（識別）をまだ選んでいない行は、工種ごとの比べ方に入りません。

## 4. Excel の取り込みと書き出し

「Excel で入れる・書き出す」から、アプリと同じ形の Excel を使えます。

- **いまの予算・内訳を書き出す**：いまの工種・実行予算・内訳が入った Excel です。直して、また取り込めます。
- **空の雛形を書き出す**：工種だけ入った、行の無い Excel です。

Excel のシートは 3 枚です。

- **実行予算**：1 行に 1 項目（工種・施工者・項目・内容・数量・単位・単価・金額）。工種・施工者・項目はプルダウンで選べます。黄色が入力、青（金額）は自動計算です。自社の労務の単価を空欄にすると、「予算の標準日当」で取り込みます。材料・リース・その他は工種を「（現場全体）」、施工者を「—」にします。工種を空欄にした労務・請負・常用の行は、工種に入らない「**予算外**」の行の予算になります（書き出しでも工種は空欄で出ます。取り込みの確認の画面に「工種なしの労務・請負・常用 N 行は予算外の予算になります」と出ます。止めずに取り込めます）。
- **受注の内訳**：区分・名称・規格・仕様・数量・単位・単価・金額・工種（識別）。元請けの表・見積書の表を貼り付けてもかまいません（見出しの名前で列を探します）。
- **選択肢**：A 列の 3 行目から下が工種の一覧です。ここで工種を足したり並べ替えたりすると、取り込みでその順になります。

### 取り込みの流れ

1. 「取り込む Excel」でファイルを選びます。
2. **取り込む内容の確認**が出ます。直す必要のある行があれば、シート名と行番号つきで出ます（施工者の名前がマスターの協力会社と合わない、項目と施工者の組み合わせが違う、など）。Excel を直して選び直してください。
3. 工種の変わり方を確かめます。
   - **足す工種**：Excel に新しく出てきた名前。
   - **消す工種**：Excel に無く、どこでも使われていない工種。
   - **Excel に無い工種（使用中のため残します）**：使われている工種（取り込みで入れ替えない内訳の行・日報の工種・読み替え表・進み具合の上書き）は、Excel に無くても消しません。
4. 受注の内訳の取り込み方を選びます。
   - **全部入れ替える**：新しい注文書が届いたとき。
   - **変更の行として足す**：変更の内訳だけ届いたとき（区分は「変更」になります）。「いまの予算・内訳を書き出す」で出した Excel をそのまま使うと、いまある当初の行が「変更」として二重に入ります。変更の行だけを残した Excel で取り込んでください（当初の行があると確認の画面に注意が出ます）。
5. 「取り込む」を押します。実行予算は全部入れ替わります。行の無いシートは、いまの中身を変えません。

書き出した Excel を直さずに取り込み直すと、中身はまったく同じになります。

### PDF の取り込み（受注の内訳だけ）

元請けから PDF で届いた注文書・内訳書や、お客様に出した見積書の PDF は、「Excel で入れる・書き出す」の下の「**PDF から取り込む**」で読み取れます（完了した現場では出ません）。

- 読み取れるのは**文字を選べる PDF** だけです。スキャンした画像の PDF は「文字を読み取れない PDF です（画像の PDF）」と出ます。そのときは表を Excel に貼り付けて取り込むか、画面で入れてください。
- 読み取りはお使いの端末の中で行います（PDF はアプリに送りません。取り込むのは確かめた行だけです）。

1. 「PDF から取り込む」→ PDF を選びます。
2. **列の割り当て**：表の見出し（名称・品名・規格・仕様・数量・単位・単価・金額・摘要など）から、どの列が何かを推定します。見出しが無い表は数の並びから推定します。違っていたら列ごとに「名称・規格・数量・単位・単価・金額・使わない」を選び直します（選び直すと下の表は読み直しになり、手で直したところは消えます）。
3. **行を確かめる**：行ごとに「取り込む」の印・区分（当初／変更）・名称・規格・数量・単位・単価・工種（識別）を直せます。
   - 【…】などの見出し、小計・合計・消費税の行は初めから「取り込む」を外しています（画面には出ます）。
   - 「＜変更増減分＞」のように「変更」「増減」を含む見出しより後の行は、区分を「変更」にします。
   - 金額だけの行（諸経費 1 式など）は数量 1・単価＝金額にします。「△」「▲」の付いた金額は負の数として読みます。「(1,000)」のような括弧の金額も負の数にしますが、「(2)」のような短い番号は数にしません。
   - 数量の欄に「450㎡」「3式」のように単位がくっついていれば、数量と単位に分けます。
   - 「消費税」「税込金額」のような短い行だけを合計とみます（「税込み処理費」のような明細は取り込みます）。
   - 諸経費などは「経費」、減工分・値引きなどは「減分」を初めから選びます。名称や直前の見出しに工種の名前が入っていれば、その工種を選びます。
   - 金額はアプリが数量 × 単価で計算し直します。PDF の金額と合わない行には注意が出ます。
   - 行が多いときは、上から順に**まとめて選べます**。「ページ」の印を外すと、そのページの行を全部取り込みません（総括表のページを外すと二重に数えません）。
   - 「全部の行」で全部取り込む・全部外す、工種がまだの行にまとめて工種を付ける、「工種がまだの行だけ見る」ができます。
   - 行は見出しごとにまとまっていて、見出しを押すと開いたり閉じたりします。見出しごとに「全部取り込む」「全部外す」と工種をまとめて付けることもできます。行が多いときは、工種がまだの行がある見出しだけ開いています。
4. 取り込む行の数と金額の合計を確かめ、「**全部入れ替える**」か「**変更の行として足す**」を選んで押します（Excel の取り込みと同じです）。「変更の行として足す」を選ぶと、行ごとの区分は出なくなり、すべて「変更」として足します。

PDF の作りによっては、1 つの明細が 2 行に分かれたり、列がずれたりします。確かめの画面で直すか、取り込んだ後に「受注の内訳」で直してください。

## 5. 日報で工種を選ぶ

現場に工種が 1 つ以上あると、日報の「作業内容」の行の**工種**の欄が選択になります（協力会社のアカウントでも選べます。見えるのは工種の名前だけです）。

- 工種を選ぶと、工種の文字の欄にもその名前が入ります（原価集計表・お客様用の資料はこれまでどおり文字を使います）。
- 一覧に無い作業は「（手入力）」を選び、文字を入れます。手入力の行は、下の読み替え表か工種の名前で工種を決め、どちらでもなければ「予算外の作業」になります。
- 選んでいた工種が実行予算から無くなった行は、文字の欄と注意が出ます。工種を選び直すか、「（手入力）」を選ぶか、工種の文字を直してください（そのままでは無くなった工種を指したままです）。
- 現場に工種が無いときは、これまでどおり文字の欄だけです。
- 1 日分の Excel を取り込むと、工種の文字を読み替え表 → 工種の名前の順に当てはめて工種を選んだ状態にします。当てはまらない文字はそのまま取り込み、取り込みの注意に出します。

## 6. 日報の工種の読み替え表

工種を選ぶ前に入れた日報（過去の日報）の工種の文字を、どの工種に入れるかを決める表です。日報の行は書き換えません（承認済みの日報もそのまま）。「実行予算・受注の内訳」の画面の下の「**日報の工種の読み替え**」と、「予算と実績」の画面の上に出る知らせ（割り当てていない文字があるとき）の「工種の読み替えを開く」で使います（社員と管理者だけ）。

- **まだ割り当てていない工種の文字**：現場の全日報の作業内容の行のうち、工種を選んでおらず、読み替え表にも工種の名前にも当てはまらない文字です。行の数と投入人工の合計つきで、人工の多い順に出ます。工種を選ぶと割り当てます。「予算外のまま」にした文字は「予算外の作業」として数えます。
- **割り当て済み**：割り当て先を変える・「外す」で割り当てをやめることができます。
- 工種の決め方（行ごと）は、行で選んだ工種 → 読み替え表（前後の空白を除いた文字で） → 工種の名前と同じ文字 → 予算外、の順です。
- 読み替え表で使っている工種は消せません。
- 割り当てを変えると、「予算と実績」の数字もすぐ変わります（日報の行は変わりません）。

## 7. 予算と実績の見方

現場 → 「**予算と実績**」。工期の初めから今日（日本時間）までの日報で数えます。パソコンは表、スマホはカードで同じ内容です。

| 列 | 中身 |
| --- | --- |
| 内訳の金額 | 受注の内訳のうち、その工種に識別した行の金額の合計（当初＋変更） |
| 実行予算 | その工種の実行予算の行の合計。下に自社・協力会社の人工（例「自社 80.0 人工」）。人工に数えるのは、労務・常用の行のうち単位が「人工」「人」「人日」か空欄の行の数量だけです（「式」などの行は金額だけ） |
| 実績（いままで） | その工種に振り分けた労務費と人工 ＋ その工種の外注の支払い（外注の買掛） |
| 進み具合 | 棒と %（下の「進み具合」） |
| このままの見込み | 請負の見込み（請負額）＋ 人工の実績 ÷ 進み具合。このまま進むと最後にかかる金額 |
| 見込みの粗利 | 内訳の金額 − 見込み（赤字は赤） |
| 判定 | 下の「判定」 |

- **工種名を押す**と、施工者ごとの行、% の上書き、その工種の日報の作業（日付・作業内容の行・数量・投入人工・振り分けた人工と金額・外注の支払い）が開きます。日は新しい順で、多いときは「すべての日を表示」で全部出ます。
- 施工者ごとの行は次の順です（スマホのカードでは「請負」と「人工（自社・常用）」の 2 つのまとまり）。
  - **{会社}・請負**：請負額（実行予算の請負の行）／支払い（日報の外注の買掛のうち、その工種・その会社の分の合計）／見込み。
  - **自社・労務**：実行予算（人工）／実績（人工）／見込み（実績 ÷ 進み具合）。
  - **{会社}・常用**：協力会社の常用の分。請負に入っている会社の常用（作業員の行の「うち常用の時間」の分）は「**常用（請負外）**」と出ます。
  - その下に**出面**の 1 行（例「出面：自社 1.5 人工　東北建興 2.0 人工（うち請負 1.5・常用 0.5）」）。請負の会社の人工は出面には全部出ますが、原価（実績）には常用の分だけ数えます。
- **請負の実績と見込み**：日報の買掛で区分「外注」・工種・支払先（協力会社）を選んだ行が、その工種のその会社の請負の実績（支払い）になります。出来高払いで何回に分けて入れてもかまいません。外注の買掛は「現場全体」には入りません。
  - 請負の見込みは請負額です。支払いの合計が請負額を超えたら、見込みは支払った金額になり「**請負額を超えています**」と出ます。実行予算に請負の行の無い会社への外注は「**実行予算に請負額がありません**」と出ます（見込みは支払った金額）。
  - 請負額は実行予算の請負の行だけから取ります（現場の「協力会社と作業員」の請負金額は使いません）。
  - 根拠（件）を選んだ外注の行は「**追加の発注（件）**」として、その工種の実績と見込みに足しますが、請負額を超えたかどうかの比べには入れません。
  - 工種を選んでいない外注の行は「予算外の作業」に「**うち工種なしの外注**」として出ます。日報の外注の行で工種を選んでください。
- 実績の振り分け：日報 1 日ごとに、労務費・人工を作業内容の行の投入人工の比で工種に分けます。協力会社は、実行予算でその会社を施工者に入れた工種が 1 つならそこへ全部、2 つ以上ならそれらの工種の比、どこにも入れていない会社はその日の比です。投入人工が空欄の行は、その日のほかの行の平均として数えます。その日に工種の決まった作業内容の行が無ければ、その日の分（協力会社も）は全部「予算外の作業」です。
- **予算外の作業**：工種の決まらない作業（常用・契約外・現場判断の件など）の人工と労務費です。実績があると「**追加の請求を検討**」の札が出ます。押すと施工者ごとの行と日報の作業が開きます。
- **繰越（工種なし）**：Excel から途中でアプリに移した現場の、作業員ごとの繰越初期値（管理 → 現場）の合計です。工種が分からないので予算外の欄に別の行で出し、合計の実績に数えます。繰越のある作業員の、繰越の基準日より前の日報の行は二重に数えません。
  - そのため、合計の実績の労務費は「工事原価集計表」の ① 原価合計の労務費と一致しないことがあります（① は日報の行だけを数え、繰越初期値を入れず、基準日より前の行も数えます）。繰越の無い現場では一致します。
- **現場全体（材料・リース・燃料・その他）**：工種に分けません。内訳の金額の欄は受注の内訳の経費、実行予算は材料・リース・その他、実績は日報の燃料・リース・現金・買掛（仕入）の合計です（外注の買掛は入りません）。
- **合計**：内訳の金額は受注の内訳のすべての行（工種・経費・減分・工種を付けていない行）の合計です。実行予算・実績は工種・予算外・繰越・現場全体の合計です。

### 進み具合

- **数量から**：日報のその工種の施工数量の合計 ÷ 受注の内訳のその工種の数量（当初＋変更）。単位が同じ行だけで数えます（㎡ と m2、全角と半角は同じ）。内訳の単位が複数あれば金額の大きい単位で比べます。単位の合う数量の行が日報に無い（「式」だけ、など）ときは出しません。
- 数量からが 100% を超えると「**内訳の数量より多く施工しています**」と出ます（内訳の数量が違うか、日報の数量の入れ間違いの合図）。見込みには 100% として使います。
- **棒**：青＝使っている進み具合（% の上書きがあればそれ、なければ数量から）。赤い線＝数量からの %。青と赤がずれているときは、内訳の数量か上書きの % を見直してください。

### 判定

| 札 | 意味 |
| --- | --- |
| 順調 | 見込みが実行予算以内 |
| 予算超え | 見込みが実行予算を超えるが、内訳の金額以内 |
| 赤字の見込み | 見込みが内訳の金額を超える（実行予算が内訳の金額より大きくても、こちら） |
| — | 進み具合が無い・0% で、見込みを出せない（請負だけの工種は、進み具合が無くても請負額で見込みを出します） |
| —（内訳の識別がまだです） | 見込みは出ているが、その工種に識別した受注の内訳の行が 1 行も無く、内訳の金額と比べられない。「実行予算・受注の内訳」で内訳の行の工種（識別）を選んでください（見込みの粗利も「—」） |

## 8. 集計 Excel の書き出し

「予算と実績」の「**Excel に書き出す**」で、画面より細かい社内用の Excel を書き出します（今日までの日報で数えます。社員と管理者だけ）。シートは 7 枚です。

### PDF で見る・保存する

「実行予算・受注の内訳」と「予算と実績」の上の「**PDF で見る**」で、アプリの PDF ビューアーが同じ画面で開きます（「戻る」で元の画面に戻ります）。「**PDF を保存**」はそのままダウンロードします。社員と管理者だけです。

- **実行予算・受注の内訳の PDF**：実行予算（工種ごとの施工者の行と小計、工種なしの予算、現場全体、合計）、受注の内訳（区分・名称・規格・数量・単位・単価・金額・工種の識別）、工種ごとの内訳の金額（当初・変更）。保存した内容で作ります（画面で直して保存していない内容は入りません）。
- **予算と実績の PDF**：画面と同じ列・判定の表（予算外の作業・繰越・現場全体・合計を含む）、工種ごとの施工者の明細、現場全体の内わけ、作成日時。今日までの日報で数えます。
- A4 縦です。列の多い表は文字を小さくして横 1 枚に収め、行の途中ではページを分けません。

## 9. 進み具合の % の上書き

数量から出せない工種（「式」の工種など）や、数量からの % が実際と合わない工種は、% を入れて上書きできます。

- 入れられるのは**管理者**と、**その現場の確認者・承認者**（社員）だけです。ほかの人には今の上書きと履歴だけ見えます。職長は日報に数量を入れるだけです。
- 「予算と実績」で工種名（スマホは「施工者・% の上書き・日報の作業を開く」）を押し、0〜100 の % を入れて「**% を上書き**」を押します（小数は 1 桁まで）。
- 「**上書きを外す**」で数量からの % に戻ります。
- 入れた人と日時が残り、「上書きの履歴」に新しい 5 件まで出ます。
- 上書きは工種に付くので、Excel の取り込み直しでは消えません。完了した現場では変えられません。
