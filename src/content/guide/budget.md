# 実行予算と元請けの内訳

元請けから渡された内訳（注文書）と、自分たちで組んだ実行予算を、現場ごとに**工種**で分けて持ちます。いまの段階でできるのは、工種・実行予算・元請けの内訳を入れること（画面と Excel）です。

次の段階で追加するもの：日報の作業内容の行で工種を選ぶ、過去の日報の工種の文字を工種に読み替える表（読み替え表）、工種ごとの進み具合（%）の上書き、「予算と実績」の画面（工種ごとに内訳の金額・実行予算・実績・見込みを比べる）。

この画面を使えるのは**社員と管理者だけ**です。協力会社のアカウントには、金額・予算・内訳は見えません（日報で選ぶための工種の名前だけ見えます）。

現場を開き、「**実行予算・元請けの内訳**」を押すと開きます。完了した現場は閲覧と Excel の書き出しだけできます。

## 1. 工種

実行予算と内訳を分ける単位です（例：剥離・ブラスト・塗装）。

- 「＋ 工種を追加」で足し、名前を入れて「工種を保存」を押します。↑↓ で並べ替えられます。
- 名前を変えるのはこの画面だけです。Excel で名前を変えると、**別の工種として足されます**。
- 実行予算・元請けの内訳で使われている工種は消せません（次の段階で追加する日報の工種・読み替え表・進み具合の上書きで使われた工種も消せません）。
- 「経費」「減分」「現場全体」は Excel の印に使うので、工種の名前にはできません。

## 2. 実行予算

工種ごとのまとまりの下に、施工者ごとの行を入れます。協力会社が 2 社・3 社でも、行を足すだけでほかの工種はずれません。

| 項目 | 施工者 | 入れ方 |
| --- | --- | --- |
| 労務 | 自社 | 人工 × 日当。単価の初期値は「予算の標準日当」です（行ごとに書き換えられます） |
| 請負 | 協力会社 | 1 式いくら、など |
| 常用 | 協力会社 | 人工 × 単価 |
| 材料・リース・その他 | — | 工種に分けず「現場全体」に入れます |

- **予算の標準日当**は全社の設定です（管理 → マスター → 労務の設定。既定は 20,000 円）。管理者が変えられます。現場の「常用単価の既定」は客先に請求する単価なので、予算には使いません。
- 協力会社は、マスターで**協力会社の印**のある会社から選びます。
- 金額は数量 × 単価で、1 円未満は四捨五入します。
- 「実行予算を保存」を押すと、実行予算の行を全部入れ替えます。

## 3. 元請けの内訳

元請けの内訳の行（区分・名称・規格・数量・単位・単価・金額）を入れ、右端の「**工種（識別）**」でどの工種の分かを選びます。

- **経費**（諸経費など）と**減分**（減工分など）は工種に入れず、内訳の金額の合計にだけ数えます。
- 区分は「当初」と「変更」です。変更の内訳が届いたら、区分を「変更」にして行を足します。
- 工種（識別）をまだ選んでいない行は、工種ごとの比べ方に入りません。

## 4. Excel の取り込みと書き出し

「Excel で入れる・書き出す」から、アプリと同じ形の Excel を使えます。

- **いまの予算・内訳を書き出す**：いまの工種・実行予算・内訳が入った Excel です。直して、また取り込めます。
- **空の雛形を書き出す**：工種だけ入った、行の無い Excel です。

Excel のシートは 3 枚です。

- **実行予算**：1 行に 1 項目（工種・施工者・項目・内容・数量・単位・単価・金額）。工種・施工者・項目はプルダウンで選べます。黄色が入力、青（金額）は自動計算です。自社の労務の単価を空欄にすると、「予算の標準日当」で取り込みます。材料・リース・その他は工種を「（現場全体）」、施工者を「—」にします。
- **元請けの内訳**：区分・名称・規格・仕様・数量・単位・単価・金額・工種（識別）。元請けの表を貼り付けてもかまいません（見出しの名前で列を探します）。
- **選択肢**：A 列の 3 行目から下が工種の一覧です。ここで工種を足したり並べ替えたりすると、取り込みでその順になります。

### 取り込みの流れ

1. 「取り込む Excel」でファイルを選びます。
2. **取り込む内容の確認**が出ます。直す必要のある行があれば、シート名と行番号つきで出ます（施工者の名前がマスターの協力会社と合わない、項目と施工者の組み合わせが違う、など）。Excel を直して選び直してください。
3. 工種の変わり方を確かめます。
   - **足す工種**：Excel に新しく出てきた名前。
   - **消す工種**：Excel に無く、どこでも使われていない工種。
   - **Excel に無い工種（使用中のため残します）**：使われている工種（取り込みで入れ替えない内訳の行と、次の段階で追加する日報の工種・読み替え表・進み具合の上書き）は、Excel に無くても消しません。
4. 元請けの内訳の取り込み方を選びます。
   - **全部入れ替える**：新しい注文書が届いたとき。
   - **変更の行として足す**：変更の内訳だけ届いたとき（区分は「変更」になります）。「いまの予算・内訳を書き出す」で出した Excel をそのまま使うと、いまある当初の行が「変更」として二重に入ります。変更の行だけを残した Excel で取り込んでください（当初の行があると確認の画面に注意が出ます）。
5. 「取り込む」を押します。実行予算は全部入れ替わります。行の無いシートは、いまの中身を変えません。

書き出した Excel を直さずに取り込み直すと、中身はまったく同じになります。
